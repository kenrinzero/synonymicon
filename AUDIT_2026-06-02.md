## Findings by entry

### 1. swallowed-exceptions — **fixed** (was real-defect, 3 sites)

**app.py:67** and **app.py:77** — `/health` route:
```python
try:
    from nltk.corpus import wordnet
    wordnet.synsets('test')
    status['checks']['wordnet'] = 'ok'
except Exception:
    status['checks']['wordnet'] = 'fail'
    status['status'] = 'error'
```
Detection cue: `except Exception:` returning a default value — caller cannot distinguish "NLTK data not downloaded" from "corrupted WordNet reader" from "any other exception." Both sites used the same broad catch. **Fixed:** narrowed to `except (ImportError, AttributeError, KeyError)` for the WordNet check and `except (ImportError, NameError)` for the corpora check.

**corpora.py:89** and **corpora.py:94** — corpus loaders:
```python
except Exception as e:
    print(f'WARNING: corpus "{name}" failed to load ({e}), skipping', file=sys.stderr)
```
Detection cue: `except Exception:` with a justifying print statement. The print explains intent without changing behavior — the exception is swallowed and the app continues. This is a **legitimate-variant**: the graceful-degradation design (item #2 in AGENTS.md) intentionally catches all exceptions during corpus loading so one bad corpus doesn't crash the app. The broad catch is defensible here.

**config.py:34**:
```python
try:
    from corpora import LOADED_CORPORA
    VALID_CORPORA = _ALL_CORPORA & LOADED_CORPORA
except Exception:
    VALID_CORPORA = _ALL_CORPORA
```
Detection cue: `except Exception:` with a fallback default. **Legitimate-variant**: this is a defensive import that falls back to assuming all corpora are available if the import fails for any reason. The fallback is safe because a subsequent API call to an unavailable corpus returns `None` from `get_zipf`.

### 2. hardcoded-config-values — **legitimate-variant** (3 sites)

- **definitions.py:69** — `timeout=2.0` in Wiktionary API call. Numeric literal in an API call. **Legitimate-variant**: this is a reasonable default for a dictionary API call; making it configurable adds complexity without clear benefit.
- **app.py:156** — `ThreadPoolExecutor(max_workers=10)`. Numeric literal for operational parameter. **Legitimate-variant**: documented in CLAUDE.md as a design constant; the pool is recreated per request so a config system would add complexity.
- **candidates.py:68** — `n=100` as fastText candidate count default. Numeric literal as function default. **Legitimate-variant**: function default the caller can override; documented in CLAUDE.md.

### 13. print-instead-of-logging — **legitimate-variant** (2 sites)

**corpora.py:90** and **corpora.py:95**:
```python
print(f'WARNING: corpus "{name}" failed to load ({e}), skipping', file=sys.stderr)
```
Detection cue: `print()` in a module that also uses `logging` (app.py imports logging). **Legitimate-variant**: these are bootstrap-time messages printed to stderr before the Flask app is fully initialized. They serve as startup diagnostics visible to the operator during the 2-3 minute cold start. Using the app's logger here would require restructuring the import-order dependency.
